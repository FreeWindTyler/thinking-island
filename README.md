# 思维小岛

思维小岛是一个面向一年级孩子的数学思维锻炼项目。它借鉴 Duolingo 式短关卡、即时反馈、连续学习和经验值机制，让孩子在轻量练习里建立数感、规律观察、比较推理、应用题理解和空间意识。

当前版本是无需安装依赖的静态 Web 应用，适合作为 GitHub 开源项目的第一版。

## 功能

- 5 个思维关卡：数感热身、规律侦探、比较高手、故事算一算、空间观察
- 每关 5 道一年级友好的题目
- 即时反馈和解题说明
- 经验值、星星、连续天数
- 本地浏览器保存学习进度
- 适配桌面和手机屏幕

## 本地运行

直接用浏览器打开 `index.html` 即可。

如果你希望通过本地服务预览，也可以在项目目录运行：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080`。
