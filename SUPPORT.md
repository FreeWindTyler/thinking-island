# Support

Thinking Island is an early open-source education project. Please use GitHub issues for public support and project feedback.

## Where to Ask

- Bug reports: open an issue with the `Bug report` template
- Feature ideas: open an issue with the `Feature request` template
- Question content proposals: open an issue with the `Question content` template
- Release or deployment questions: open a regular issue and include the workflow or browser context

## Child Safety and Privacy

Do not include real child names, school names, contact details, account data, or other private information in public issues.

If you are reporting a child-safety or privacy concern, describe the risk without sharing sensitive personal data.

## Project Scope

The project currently focuses on elementary math thinking practice, with the public route focused on grade 1 foundations and future content planned for grades 1-3:

- number sense
- patterns
- comparison
- story problems
- spatial observation

Requests outside this scope may be deferred until the core learning loop is stable.
